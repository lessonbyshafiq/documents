📦 ফেজ ১: পরিবেশ ও প্রজেক্ট কনফিগারেশন (০% - ১৫%)

    ধাপ ১.১ [Environment]: আপনার লোকাল মেশিনে একটি ডিরেক্টরি তৈরি করুন এবং একটি আইসোলেটেড ভার্চুয়াল এনভায়রনমেন্ট সচল করুন।

    ধাপ ১.২ [Dependencies]: প্রয়োজনীয় প্যাকেজসমূহ ইনস্টল করুন: django, django-crispy-forms (ফর্ম সুন্দর করার জন্য), এবং ডাটাবেজ ড্রাইভার (যদি SQLite বাদে PostgreSQL/MySQL ব্যবহার করেন)।

    ধাপ ১.৩ [Initialization]: জ্যাঙ্গো কোর প্রজেক্ট (job_qbank_project) এবং আপনার অ্যাপ (qbank) তৈরি করুন।

    ধাপ ১.৪ [Settings Configuration]: settings.py-তে গিয়ে INSTALLED_APPS-এ আপনার অ্যাপ যুক্ত করুন, টাইমজোন (Asia/Dhaka) ঠিক করুন এবং STATIC ও MEDIA ফাইলগুলোর পাথ সেট করুন।

🗄️ ফেজ ২: ডাটাবেজ মডেলিং ও মাইগ্রেশন (১৫% - ৩০%)

    ধাপ ২.১ [Models Translation]: qbank/models.py ফাইলে আপনার তৈরি করা SQL স্কিমাকে জ্যাঙ্গো ORM ক্লাসে রূপান্তর করুন (Subject, Chapter, Topic, Question, Tag, MCQOption, TrueFalseAnswer, DescriptiveAnswer)।

    ধাপ ২.২ [Relationships]: নিশ্চিত করুন যে Foreign Key এবং One-to-One রিলেশনগুলোতে on_delete=models.CASCADE এবং রিভার্স কোয়েরির জন্য related_name সঠিকভাবে দেওয়া হয়েছে।

    ধাপ ২.৩ [Compilation]: টার্মিনালে python manage.py makemigrations রান করে পাইথন কোডকে ডাটাবেজ ব্লুপ্রিন্টে রূপান্তর করুন।

    ধাপ ২.৪ [Execution]: python manage.py migrate রান করে বাস্তব ডাটাবেজ টেবিলগুলো তৈরি করুন।

🛡️ ফেজ ৩: অ্যাডমিন প্যানেল ও ডেটা সিডিং (৩০% - ৪৫%)

    ধাপ ৩.১ [Superuser]: অ্যাডমিন প্যানেলে ঢোকার জন্য একটি প্রধান অ্যাডমিন অ্যাকাউন্ট তৈরি করুন: python manage.py createsuperuser।

    ধাপ ৩.২ [Admin Registration]: qbank/admin.py ফাইলে সবকটি মডেল রেজিস্টার করুন যেন ব্রাউজার থেকে ডেটা এন্ট্রি করা যায়।

    ধাপ ৩.৩ [Tabular Inlines]: QuestionAdmin-এর ভেতর MCQOptionInline এবং TrueFalseAnswerInline যুক্ত করুন, যাতে একটি প্রশ্ন তৈরি করার সময় একই স্ক্রিনেই তার অপশন বা সত্য/মিথ্যা উত্তর লিখে ফেলা যায়।

    ধাপ ৩.৪ [Data Seeding]: অ্যাডমিন প্যানেলে লগইন করে পরীক্ষামূলকভাবে ১টি সাবজেক্ট, ২টি চ্যাপ্টার, কয়েকটি টপিক এবং ৩টি ভিন্ন টাইপের (MCQ, TF, Broad) প্রশ্ন ইনপুট দিন।

🖥️ ফেজ ৪: ফ্রন্টএন্ড ইন্টিগ্রেশন ও ইউজার অথেন্টিকেশন (৪৫% - ৬৫%)

    ধাপ ৪.১ [Template Setup]: প্রজেক্টের ভেতরে templates/ ফোল্ডার তৈরি করে আপনার আগের তৈরি করা তিনটি ফাইল রাখুন: login.html, register.html, এবং dashboard.html।

    ধাপ ৪.২ [Authentication Views]: জ্যাঙ্গোর বিল্ট-ইন LoginView এবং LogoutView ব্যবহার করুন। নতুন ইউজারের জন্য UserCreationForm এক্সটেন্ড করে একটি কাস্টম রেজিস্ট্রেশন ভিউ তৈরি করুন।

    ধাপ ৪.৩ [Form Replacement]: আপনার দেওয়া HTML ফর্মগুলোর ভেতরের স্ট্যাটিক <input> ফিল্ডগুলোকে জ্যাঙ্গোর ডাইনামিক {{ form.as_p }} বা ম্যানুয়াল ফিল্ড রেন্ডারিং দিয়ে প্রতিস্থাপন করুন।

    ধাপ ৪.৪ [Static Files]: Tailwind CDN এবং FontAwesome লিঙ্কগুলো বেস টেমপ্লেটে ঠিক রাখুন এবং জ্যাঙ্গোর {% load static %} ট্যাগ ব্যবহার নিশ্চিত করুন।

🧠 ফেজ ৫: ড্যাশবোর্ড লজিক এবং বিজনেস ইন্টেলিজেন্স (৬৫% - ৮৫%)

    ধাপ ৫.১ [Dashboard View]: একটি ভিউ তৈরি করুন যা শুধুমাত্র লগইন করা ইউজাররা দেখতে পাবেন (@login_required ডেকোরেটর ব্যবহার করে)।

    ধাপ ৫.২ [Query Aggregation]: ডাটাবেজ থেকে এগ্রিগেট কোয়েরি চালিয়ে ইউজারের ড্যাশবোর্ডের ডেটা প্রসেস করুন:

        মোট সম্পন্ন পরীক্ষা, মোট পড়া প্রশ্ন, এবং বিষয়ভিত্তিক দুর্বলতা (এর জন্য ইউজার কতটি ভুল উত্তর দিয়েছে তার ওপর একটি কাউন্ট কোয়েরি চালাতে হবে)।

    ধাপ ৫.৩ [Dynamic Table rander]: ড্যাশবোর্ডের স্ট্যাটিক টেবিল ডেটা মুছে দিয়ে {% for exam in recent_exams %} লুপ চালিয়ে বাস্তব পরীক্ষার রেজাল্ট ডাটাবেজ থেকে এনে টেবিলে বসান।

    ধাপ ৫.৪ [Search Mechanism]: ড্যাশবোর্ডের সার্চ বারের জন্য একটি Q অবজেক্ট কোয়েরি লিখুন যা টপিক বা প্রশ্নের টেক্সট ফিল্টার করতে পারে।

🧪 ফেজ ৬: টেস্টিং, সিকিউরিটি এবং ফাইনাল অপ্টিমাইজেশন (৮৫% - ৯৫%)

    ধাপ ৬.১ [Unit Testing]: জ্যাঙ্গোর tests.py ব্যবহার করে প্রশ্ন আপলোড এবং ইউজার লগইনের লজিকগুলো টেস্ট করুন।

    ধাপ ৬.২ [Security Check]: settings.py ফাইলে DEBUG = False করুন, সিক্রেট কি (SECRET_KEY) পরিবেশ ভেরিয়েবলে (.env ফাইল) সরিয়ে নিন।

    ধাপ ৬.৩ [Database Query Tuning]: ডাটাবেজের ওপর যেন চাপ না পড়ে সেজন্য select_related() এবং prefetch_related() ব্যবহার করে আপনার কোয়েরি অপ্টিমাইজ করুন (যেমন: প্রশ্ন ও তার অপশনগুলো এক কোয়েরিতে আনা)।

🌐 ফেজ ৭: ডেপ্লয়মেন্ট ও লাইভ (৯৫% - ১০০%)

    ধাপ ৭.১ [Production Database]: লোকাল SQLite ডাটাবেজ পরিবর্তন করে লাইভ প্রোডাকশনের জন্য PostgreSQL বা MySQL ডাটাবেজ কানেক্ট করুন।

    ধাপ ৭.২ [Static Gathering]: লাইভ সার্ভারে সব সিএসএস ও জাভাস্ক্রিপ্ট এক জায়গায় জড়ো করতে python manage.py collectstatic কমান্ড রান করুন।

    ধাপ ৭.৩ [Hosting]: Render, DigitalOcean অথবা PythonAnywhere-এ জ্যাঙ্গো প্রজেক্টটি পুশ করুন এবং Gunicorn/Nginx কনফিগারেশন সম্পন্ন করুন।
